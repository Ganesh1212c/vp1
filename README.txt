Vettiyil Packaging - new website
================================
Open index.html in any browser to view the site. No installation needed.

Pages:  index.html (Home), about.html, products.html, sustainability.html,
        infrastructure.html, contact.html
Files:  assets/style.css (design), assets/main.js (menu, gallery, video, form)

Images and the logo are loaded from the company's current website
(vettiyilpackaging.com/wp-content/uploads/...). When the site moves to its own
hosting, copy those images into an "images" folder and update the links, so the
site no longer depends on the old one.

The quote form opens the visitor's email app addressed to sales@vettiyilpackaging.com.
